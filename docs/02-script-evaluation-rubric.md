# ScriptLens 评分方法论（爆款短剧 5 维 rubric）

PRD §6 定了 5 维度，本文给每维**工业判据 + 档位锚点 + prompt 锚点 + 失败模式**。
所有结论的锚点是"中文抖音 / 快手微短剧（单集 1-5 分钟、25-100 集、竖屏付费）"。
长剧 / 美剧 / 院线电影评分体系不适用。

---

## 1. 行业实践调研（评分维度的工业锚点）

| 来源 | 关键指标 | 引用 |
|---|---|---|
| 抖音爆款编剧手册 | 前 3 秒生死线；前 7 秒钩子；每分钟 ≥1 转折；每 7 秒视觉刺激点；完播率 ≥65% 合格、90%+ 头部 | `06dz.com/post/128481` 等 |
| 快手星芒「三维推荐模型」 | 内容标签 40% + 用户行为 30%（含完播率）+ 场景适配 30%；乡村 3 集完播 91%、职场 7 集后流失；"成长型主角" +32% 完播率 | `c.m.163.com/news/a/K64VK5K90556EH7C` |
| 反转 / 爽点工业门槛 | 平台算法门槛 ≥2.3 次反转 / 分钟；T+3 节奏（每 3 分钟一反转）；优质反转点 22-28 秒区间占 79%；伏笔密度 ≥1.2 个 / 500 字；含有效反转完播率 58-82% vs 普通 30-43% | `cpyu.net/post/80376` |
| 国家广电监管口径 | 「八关」（导向 / 片名 / 内容 / 审美 / 人员 / 片酬 / 宣传 / 播出）；6 类红线（色情低俗 / 血腥暴力 / 格调低下 / 审美恶俗 / 炫富拜金 / 畸形审美 / 炒星）；100w / 30-100w / <30w 三级备案 | `nrta.gov.cn/art/2022/12/27/art_113_63062` |

## 2. 第一性原理：成片秒数 → 剧本可观测信号

调研里所有指标基于**成片视频秒数**（"3 秒"、"22-28 秒"），剧本是文本，没法测秒数。剧本侧的代理量必须显式定义，否则 LLM 评分会幻觉。

| 成片维度 | 剧本侧代理量（系统真正读到的信号） |
|---|---|
| 前 3 秒 / 前 7 秒钩子 | 第 1 集第 1 场前 N 段（默认 N=20，对应短剧 ~30 秒）是否包含「冲突 / 反差 / 危机」事件 |
| 每分钟 1 个转折 | 单集场景数 ≥ 5（短剧每场 ≈ 1 分钟）；每场至少 1 次「角色行动 / 关系变化 / 信息揭露」 |
| 每 7 秒视觉刺激 | 不可观测（剧本无镜头），降级为「场内动作行 / 转场行（▲△）密度 ≥ 1 / 100 字」 |
| 反转 ≥2.3 次 / 分钟 | 不可观测，降级为「reward 事件 / 集数 ≥ 2.3」（reward = 反转 / 打脸 / 逆袭 / CP 进展 / 信息揭露） |
| 完播率 65% | 不可观测，**不预测**完播率，只评结构因子 |
| 备案分级 | 元数据缺失，**不假装能判定备案级**，只输出"需要重点 / 普通 / 平台 审核"的相对建议 |

**不变式**：rubric 只对**剧本中可观测的字面信号**评分；任何"秒数"出现在 prompt 里都视为污染。Agent 工具 `score_dimension` 的输入只有「场景文本 + 场号 + 角色行 + 动作行」，禁止凭空想象成片节奏。

## 3. 5 维档位锚点

每维 4 档（0-2 / 3-5 / 6-8 / 9-10），档位描述是**剧本字面信号**，不是主观印象。
LLM 评分时必须挑选最匹配的一档，并产出 `evidence_ref_ids` 锁定字面证据。

### 3.1 opening_hook（开场钩子强度）

读取范围：第 1 集 1-1 至 1-3 场，或前 3000 字（取较短）。

| 档 | 信号 |
|---|---|
| 9-10 | 首场 20 段内出现死亡 / 绝症 / 离婚 / 重生 / 穿越 / 阴谋揭露 / 当众羞辱 任一；首集结尾留明确钩子（悬念 / 翻牌 / 关键身份揭露） |
| 6-8 | 首场内有冲突或反差但非极强；首集前 3 场至少 2 次冲突事件 |
| 3-5 | 首集前 3 场只有 1 次冲突 / 首集前 3 场都在交代背景或日常 |
| 0-2 | 首集前 3 场只有人物介绍和环境描写，无冲突 / 首场超过 30 段没有事件 |

**Prompt 关键词**：死亡 / 绝症 / 离婚 / 出轨 / 重生 / 穿越 / 复仇 / 退婚 / 分手 / 当众 / 羞辱 / 阴谋 / 真相 / 误会 / 反目。

### 3.2 reward_density（爽点密度）

读取范围：全剧。

| 档 | 信号 |
|---|---|
| 9-10 | reward 事件总数 / 集数 ≥ 3.0 ；连续 ≥3 集无 reward 段不超过 1 处 |
| 6-8 | 比值 1.5-3.0 ；连续 ≥3 集无 reward 段 ≤ 3 处 |
| 3-5 | 比值 0.5-1.5 ；存在连续 5+ 集无 reward 段 |
| 0-2 | 比值 < 0.5 ；中后段（30-40 集类）出现连续 8+ 集无 reward |

**reward 事件**定义：打脸 / 逆袭 / 反转 / 复仇成功 / 关系突破（首吻 / 表白 / 求婚 / 结婚） / 身份揭露 / 阴谋败露 / 强势惩罚反派。
**统计方式**：Agent 工具 `extract_reward_events(script_id)` 扫全场对话与动作行，命中关键词 + LLM 判定二级过滤。

### 3.3 motivation（动机自洽度）

读取范围：每个**角色关键决策场景**（结婚 / 复仇 / 原谅 / 背叛 / 离开 / 牺牲 / 反目）。

| 档 | 信号 |
|---|---|
| 9-10 | 所有关键决策都能在 ≤5 场前找到 ≥2 个铺垫信号；OOC 次数 0 |
| 6-8 | 多数关键决策有铺垫；OOC ≤ 2 次（且角色弧线整体合理） |
| 3-5 | 至少 1 个核心决策无铺垫（如"男主毫无理由原谅反派"）；OOC 3-5 次 |
| 0-2 | 主角动机系统性崩塌（≥2 个核心决策无铺垫 / OOC > 5 次） |

**OOC**（Out Of Character）定义：角色行为与前序设定 / 已发生事件直接矛盾。
**判定流程**：先用 `locate_character_decisions` 工具抽取候选场景，再用 `score_motivation_chain` 工具对每个决策回扫 5 场上下文。

### 3.4 pacing（节奏控制）

读取范围：全剧分集。

| 档 | 信号 |
|---|---|
| 9-10 | 单集事件数（场景数 + reward 事件数）的方差 ≤ 阈值 ；无连续 3+ 集低密度段 |
| 6-8 | 方差中等；连续 3+ 集低密度段 ≤ 2 处 |
| 3-5 | 中段（按集数分前/中/后三段）出现明显塌陷（中段平均事件数 < 全剧均值 70%） |
| 0-2 | 中后段连续 5+ 集纯回忆 / 纯日常；总集数 ≥ 60 但 reward 事件 ≤ 30 |

**统计**：纯量化，不用 LLM；`score_dimension(pacing)` 内调 SQL 聚合 `scenes` 表得到分集事件序列后丢给 numpy 算方差。LLM 只负责把数字翻译成文字 reason。

### 3.5 risk（审核风险等级）

读取范围：全剧。risk 是分级输出，不是 0-10 连续分。

| 档（level） | 信号（任一命中即升级） |
|---|---|
| **high_risk**（红线，得分 0-2） | 涉未成年涉性 / 涉政敏感 / 民族宗教歧视 / 自杀方法学 / 毒品制作描写 |
| **medium_risk**（得分 3-5） | 拜金炫富主线 / 暴力血腥连续场景（≥3 场） / 三观争议（小三上位 / 报复美化） / 涉医违规（虚假治疗 / 代孕） |
| **low_risk**（得分 6-8） | 局部低俗台词（≤5 处） / 偶发暴力（1-2 场，非主线） / 轻度擦边（暧昧而非露骨） |
| **clean**（得分 9-10） | 无以上命中；导向、人物动机正向；无擦边台词 |

**判定流程**：
1. 关键词扫描（PRD 配套词表 `risk_terms.json`，初版手工整理 ~200 词，覆盖广电六大类红线）
2. 命中场景丢给 LLM 二级判定（防止"杀人"出现在台词比喻里被误判）
3. 输出 `risk.level` + 命中场景列表 + 等级建议（reference 备案三级，**不直接判 100w / 30w 备案**，只输出"建议按 X 级走审核"）

**与 PRD 对齐**：risk 维度的 `level` 字段映射到 `scorecard[].level: 'clean' | 'low_risk' | 'medium_risk' | 'high_risk'`，其他 4 维 level 仅 `high / medium / low` 三档。

## 4. 评分 prompt 锚点（D2-4 实装基础）

### 4.1 通用骨架（5 维共用）

```text
你是中文短剧评分专家。读取下面【场景文本】，**只**根据字面信号判断 {dimension} 维度，
不能基于成片镜头 / 成片秒数 / 你脑补的演绎效果打分。

【档位锚点】
{rubric_table}    # §3 对应小节复制进来

【场景文本】
{retrieved_scenes}  # RAG 检索回来的 N 场原文（带 scene_no）

【输出 JSON 严格契约】
{
  "score": <0-10 整数>,
  "level": "<high|medium|low|high_risk|medium_risk|low_risk|clean>",
  "reason": "<≤80 字，必须引用具体场号或角色名>",
  "evidence_ref_ids": ["scene_xxx", ...]   # 必须 ≥1 条，从【场景文本】里挑
}

【硬约束】
1. evidence_ref_ids 为空 → 你的输出无效，重新打分。
2. reason 中不准出现"秒"、"镜头"、"画面"、"特效"等成片词汇。
3. score 与 level 必须落到上面档位锚点的同一档；档位描述命中即给该档分。
```

### 4.2 模型选择

| 工具调用 | 模型 | 理由 |
|---|---|---|
| `score_dimension`（5 维 LLM 评分） | `OPENAI_MODEL_NAME=gpt-5.2`（PRD 主路径） | 评分主要负载，质量优先；DashScope 兜底 |
| `extract_reward_events`（关键词 + LLM 二级判定） | `gpt-5-mini` 或同等小模型 | 高频调用、单次任务简单，省成本 |
| `score_motivation_chain`（5 场上下文回扫） | `gpt-5.2` | 推理链长，需大模型 |
| `risk_screening`（关键词层 + LLM 二级） | 关键词层无 LLM；二级用 `gpt-5-mini` | 关键词命中只是召回，召回精度由小模型确认 |

### 4.3 工具签名（D2-4 落地）

```text
score_dimension(script_id, dimension) -> {score, level, reason, evidence_ref_ids}
locate_scene(script_id, query|scene_no|character) -> [scene_id...]
extract_quote(scene_id, max_chars=90) -> {quote, start_line, end_line}
extract_reward_events(script_id) -> [{scene_id, type, evidence}]
score_motivation_chain(script_id, decision_scene_id) -> {score, missing_setup}
risk_screening(script_id) -> {level, hits: [{scene_id, category, term}]}
rewrite_scene(scene_id, target_dimension) -> {original, rewritten, diff, rationale}
```

ReAct 主循环编排：`opening_hook` / `reward_density` / `pacing` / `risk` 4 维基本走 `extract_*` + LLM 评分；`motivation` 走「定位决策点 → 回扫 5 场上下文 → 评分」三步。

## 5. ScriptLens 自身评估方法（meta-eval）

PRD §10 P2 要求"提供解析效果评估方法"，对应 D3 任务。

### 5.1 三层评估

| 层 | 测什么 | 怎么测 |
|---|---|---|
| L1 字面证据召回 | 评分 reason 引用的场号是否真实存在 | 自动：解析 `evidence_ref_ids`，校验 vs `scenes` 表 |
| L2 维度分一致性 | 同一剧本跑 3 次，5 维分数标准差 | 自动：跑 3 次取均值与 std，std > 1.5 视为不稳 |
| L3 与人工判分相关性 | 5 份人工标注剧本的 5 维分 vs 系统分 | 半人工：用「评分锚点匹配度」打 0/1，求 5 份均值 |

### 5.2 离线 benchmark 集

从 `eval/短剧剧本/爆款短剧剧本（完整本）/` 43 份里选 5 份覆盖：
- 1 份「公认爆款」（多反转 + 强钩子）
- 1 份「平庸日常向」（弱钩子 + 低密度）
- 1 份「中段塌陷」（前期强后期拖）
- 1 份「擦边题材」（医疗 / 三观争议）
- 1 份「fallback 路径」（无标准场号需启动 fixed_window 兜底）

人工对每份给出**预期 5 维档位 + 必读 3 场**，作为 ground truth。
系统输出与 ground truth 比对：档位完全一致计 1.0、相邻档计 0.5、跨档计 0。L3 通过线 = 5 份均值 ≥ 0.7。

### 5.3 不做的事

- 不预测完播率、播放量、商业表现
- 不与其他 Agent 产品对比 benchmark（题目不要求）
- 不做线上 A/B；MVP 没有真实用户

## 6. 失败模式与边界

| 输入特征 | 系统行为 |
|---|---|
| 无场景标记纯小说体（`fixed_window` fallback） | `pacing` 标记不可用、置 `confidence=low`；`opening_hook` / `reward_density` / `motivation` / `risk` 仍按段落顺序评 |
| 单集字数 < 200 | 当前集纳入"信息缺失" 警告，不参与方差计算 |
| 集数 < 5 | `pacing` 维度不输出（样本量不够）；其他 4 维照常 |
| 总字数 > 50 万 | PRD §9 已拒绝输入；rubric 不处理 |
| 含外语剧本 / 古文剧本 | rubric 关键词词表无效，`risk` 降级为 LLM 全文判定，置 `confidence=low` |
| LLM 返回无 evidence | 整次评分丢弃，重试一次；二次仍无证据 → 标记该维 `score=null, level=null, reason="证据不足"` |

- 本文不替换 PRD §6，而是**为 PRD §6 提供工业判据补全**。

- D2-4 实装时，prompt 模板从本文 §4 取，档位描述从本文 §3 取，PRD §6 的 `失败模式` 表与本文 §6 同步。

## 8. 后续可能的迭代方向（非 MVP）

| 方向 | 触发条件 |
|---|---|
| 增加 character_appeal（角色辨识度）维度 | 验收时反馈"5 维不够"或人工标注发现高分剧本里"角色记忆点"是独立信号 |
| 把关键词词表换成 NER + 三观分类器 | risk 关键词漏判率 > 30% 时升级 |
| 完播率回归模型 | 拿到平台真实数据 ≥ 1000 部带完播率标注的剧本后 |

**触发判断以运行时指标为准，不在 MVP 阶段提前决策。**
