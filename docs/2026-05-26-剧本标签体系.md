# 剧本标签体系

更新时间：2026-05-28
tag_set_ver：`script`（单文件清洁版本）

本文档定义 ScriptLens 剧本侧的标签字段集。英文 key 是入库、抽取、聚合的稳定字段；中文名只用于前端和业务理解，可调整文案，不改 key。

字段按载体（scope）分层：

| 载体 | scope | 维度数 |
| --- | --- | ---: |
| 剧级 | `script` | 8 |
| 集级 | `episode` | 4 |
| 情节单元 | `plot_unit` | 23 |
| 角色 | `character` | 4 |
| 关系 | `relationship` | 4 |
| **合计** |  | **43** |

稳定性结论见 [`2026-05-28-剧本标签稳定性.md`](2026-05-28-剧本标签稳定性.md)。

## 1. 剧级标签 script

整剧维度，多次重复输出剧级单值或多标签。

### `drama_tags`：剧级题材（多选）

闭合枚举（不接受集合外标签），输出 3–5 个，互斥组内最多取 1。30 项 enum 按互斥组分类：

- **世界观（互斥组）**：`都市言情 / 古风言情 / 古风权谋 / 玄幻仙侠 / 年代爱情`
- **主角套路（互斥组）**：`战神归来 / 总裁霸总 / 穿越 / 重生 / 系统流`
- **套路爽点（互斥组）**：`打脸虐渣 / 复仇`
- **婚恋设定（互斥组）**：`先婚后爱 / 闪婚 / 契约婚姻`
- **题材补充**：`家庭伦理 / 校园 / 职场 / 黑道 / 悬疑推理`
- **情感色彩**：`甜宠 / 虐恋 / 双向奔赴`
- **主角属性**：`女强 / 男强 / 大女主 / 大男主 / 马甲 / 神医 / 萌宝`

## 6. 与视频侧素材标签的对齐

剧本侧 43 维与 [`素材标签体系.md`](素材标签体系.md) 的视频侧字段对照：

| 字段类别 | 剧本侧 | 视频侧 | 共享口径 |

- 跨模态对齐通过共享 enum 的 value 集合，而非 plot_unit 与 video segment 一一映射
