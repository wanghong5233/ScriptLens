# 素材标签体系

更新时间：2026-05-22

本文档描述当前素材打标与标签价值分析使用的标签体系。英文 key 是入库、建模、聚合和历史对齐使用的稳定字段；中文名只用于前端展示和业务理解，后续可以调整中文文案，不应改变英文 key。

当前价值模板分析默认使用：

```text
剧级标签 drama_tags
+ 画面标签 visual_tags
+ ASR 台词标签 asr_tags
+ 情节业务粗粒度标签 plot business_* tags
```

其中情节原始细粒度标签会保留在库里用于审计、回放和后续实验，但默认不进入业务价值模板榜。

## 1. 剧级标签

剧级标签不是素材模型生成的固定枚举，来自榜单和剧数据源中的已有标签。当前库中出现过的剧级标签包括：

## 7. 当前价值模板分析口径

维度价值模板表：`drama_rank_exp_tag_dimension_template_score`

模板由四类维度组成：

| 维度 | 字段 |
| --- | --- |
| 剧级标签 | `drama_tags` |
| 画面标签 | `visual_tags` |
| ASR 台词标签 | `asr_tags` |
| 情节标签 | `plot_tags`，默认只使用 `business_*` |

前端默认展示 `type=dimension_template`，并默认筛选至少 2 类视频维度。可以切换为 3 类视频维度，即画面、台词、情节都参与。

核心评价字段：

| 字段 | 含义 |
| --- | --- |
| `video_count` | 命中该模板的素材数量 |
| `playlet_count` | 命中该模板的短剧数量 |
| `exposure_sum` | 曝光总量 |
| `avg_material_days` | 平均投放天数 |
| `weighted_interaction_rate` | 按曝光加权的互动率 |
| `avg_effect_score` | 综合效果分，综合曝光、投放天数、互动率 |
| `template_lift` | 相对剧标签基线的提升 |
| `confidence_score` | 综合 lift、样本量、剧数、复杂度后的置信分 |
