## 2. 判稳口径

每个目标重复 5 次（温度 0、固定 seed、关闭缓存）：

- 单值字段（`exact_match`）：5 次输出完全一致 → 该样本判稳
- 多值字段（`jaccard`）：5 次两两集合 Jaccard ≥ 0.7 → 该样本判稳
- 字段判稳阈值：`stable_rate = stable_count / n_samples ≥ 0.80` 即视为"能稳定打出"

抽样：`plot_unit / episode / character / relationship` 各 50 个 target，`script` 全跑 41 部。
