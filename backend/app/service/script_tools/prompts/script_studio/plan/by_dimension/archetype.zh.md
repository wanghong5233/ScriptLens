## 维度：archetype（模板力）

### 这一维度的本质

短剧投放靠"模板"识别 — 投放系统给抖音 / 红果用户推剧时，会先识别这部剧
属于哪个**已被验证的爆款模板**（逆袭 / 重生 / 赘婿 / 穿书 / 战神 / 神医 /
京圈 / 豪门虐恋 ...），再按对应受众包做定向。模板不清晰 = 投放系统抓不到
受众包 = ROI 暴跌。

### archetype 短板的典型形态

1. **模板归属模糊**：一部剧前半段像"赘婿"、后半段又像"战神"，
   投放系统看不到稳定的核心钩子。
2. **模板执行不到位**：标榜"逆袭"但主角从头到尾没有明显的"被打压 → 反转
   打脸"的爽点闭环。
3. **多模板硬糅**：在一部剧里硬塞两三个模板（"重生 + 赘婿 + 京圈"），
   导致每个模板都执行得很浅。

### archetype 改写的允许动作

- **强化已确立模板的关键节拍**：例如逆袭模板缺少"打脸时刻"，
  就在已有打压场之后加一场强反差打脸戏。
- **去除偏离主模板的支线**：如果主线是"逆袭"，但有一段莫名其妙的"穿越"
  支线，就把那段重写为符合"逆袭"模板的内容（不是删除场次，是改写内容）。
- **统一标志性台词 / 道具**：模板辨识度高的剧通常有"标志钩子"
  （战神就是"龙王令"、赘婿就是"上门女婿"等），改写时强化这类标志元素。

### archetype 改写的禁止动作

- **不要为了 archetype 一致性而删除主角**：模板要靠主角执行，把主角删了
  就不是"统一模板"是"换主角"。
- **不要凭空植入另一个模板的钩子**：如果原剧是"逆袭"模板，
  不要为了"提升模板力"硬加一段"重生回到学生时代"，那是换剧不是改剧。

### few-shot

**Bad rationale**：
> 「本场模板执行不到位，建议加强模板力。」

**Good rationale**：
> 「本场（第 7 集 / 第 4 场）是顾聿之向姜栀枝道歉的关键打脸时刻，
> 但原文里他只是低声说「对不起」，没有展现逆袭模板要求的「公开认错 +
> 主动跪求」的强反差信号；这场是逆袭模板的核心爽点节拍，应当强化。」

**Good expected_changes**：
> 「把第 22-28 行顾聿之的私下道歉改为公司会议室里当众跪请姜栀枝原谅；
> 保留姜栀枝在场、不要新增角色；台词长度与原文同量级。」
