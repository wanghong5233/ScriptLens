## 维度：monetization（变现力）

### 这一维度的本质

短剧的商业模型是**分集付费 / VIP 解锁**：前 10-15 集免费引流，
后面分集解锁。能不能让用户**在付费节点掏钱**，取决于：
- 付费节点正好踩在悬念高峰，让用户「忍不住」付费看下一集；
- 整剧能稳定推送给某个**精准受众包**（中年女性 / 银发 / 学生 / 都市白领），
  方便投放定向。

### monetization 短板的典型形态

1. **付费节点钩子弱**：本集结尾平淡过渡，没在悬念峰值上断点，
   用户没有付费冲动。
2. **付费节奏不规律**：连续 5 集都没有强钩子断点，用户付费意愿被磨平。
3. **受众包信号不清晰**：剧情不指向明确人群（既不是"全职妈妈"也不是
   "都市白领"也不是"银发"），投放系统抓不到核心受众，CPM 暴跌。
4. **付费章节解锁前没付费暗示**：用户不知道下一集会发生什么，
   也就没有付费动力。

### monetization 改写的允许动作

- **重写集末为悬念峰值**：把本集最后一场改写成「反派露面 / 关键证据现身 /
  主角危险」的强 cliffhanger 收尾。
- **强化受众包标识信号**：通过具体场景（写字楼 / 育儿场景 / 老年活动 /
  校园）和台词（涉及职场、家庭、感情、消费）让目标人群一眼识别这是
  「写给我看的剧」。
- **加付费暗示**：集末用主角内心独白 / 旁白文字 / 反派镜头暗示
  「下一集会有重大爆点」。

### monetization 改写的禁止动作

- **不要为了变现力换主角**：受众包信号通过场景 / 台词 / 道具传递，
  不需要换主角。
- **不要在剧中硬塞广告口播**：原生付费剧没有口播广告位，硬塞会破坏沉浸感。

### few-shot

**Bad rationale**：
> 「本场付费钩子弱，建议提高变现力。」

**Good rationale**：
> 「本场（第 8 集 / 末场）是本集最后一场，原文以姜栀枝下班回家结束，
> 平淡无 cliffhanger；第 8 集是付费解锁第 9 集的关键节点，需要在末场抛出
> 强悬念断点。」

**Good expected_changes**：
> 「把第 35-40 行姜栀枝回家场景重写：保留她进门、改为接到一个陌生来电
> 「你儿子在我手里」，姜栀枝表情骤变，画面定格在她惊愕的脸上结束；
> 保留场内所有角色（仅姜栀枝出镜），不要新增角色。」
