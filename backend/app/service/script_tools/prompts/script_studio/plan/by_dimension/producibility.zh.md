## 维度：producibility（可生成力）

### 这一维度的本质

AI 漫剧 / 短剧的成本结构跟传统短剧**完全不同**：

- **主角 LoRA 训练一次、跨集 / 跨剧复用**：男一 / 女一的 LoRA 训练成本是
  固定的，他们出现的场次越多，单场摊薄成本越低。**主角的高频出现是 producibility
  的优势，不是负担**。
- **次要角色 LoRA 摊薄不动**：只出现 1-2 集就消失的功能性角色（一次性的报信人、
  路人甲乙、客串配角）需要单独训练 LoRA，但出场量根本撑不起训练成本，是
  producibility 的真正痛点。
- **换景渲染贵**：每个新场景（背景图）都要独立生成 / 调色 / 灯光，
  单集换景次数越多，渲染管线越拉胯。
- **群戏渲染贵**：5 人以上同框需要多 LoRA 协调 + 复杂构图，
  容易翻车需要返工。

**结论：producibility 改写的方向是「减次要角色 / 减换景 / 减群戏密度 /
压缩无台词工具人」，不是「减主角同框 / 减主角对手戏」**。

### producibility 短板的典型形态

1. **群戏密度过高**：同一场出现 5 个以上有台词角色，且多数是配角 / 龙套。
2. **次要角色独占场**：整场围绕一个只在本集出现的功能性角色（报信人、
   律师、医生），缺少主角，LoRA 训练摊薄不下来。
3. **换景频繁**：单集换景 ≥ 6 次（住所 → 公司 → 餐厅 → 医院 → 警局 → 酒店），
   背景图工作量爆炸。
4. **无台词工具人**：场内有 2 个以上没有台词、纯背景出现的角色。

### producibility 改写的允许动作

- **合并次要角色**：把出现 1 次的角色 A 和出现 1 次的角色 B 合并成
  一个跨集出现的统一角色 C，提高 LoRA 复用率。
- **压缩群戏**：把 5 人同框场改为「3 人正面 + 2 人画外音 / 字幕」，
  或者只保留主角和反派 + 1 个见证人。
- **删除无台词工具人**：纯背景出现没有台词的角色直接删掉，让镜头集中在
  主角身上。
- **合并相邻换景**：把"主角在公司、然后去餐厅、然后回家"三段压缩到
  "主角在公司加班 → 接到电话 → 直接回家"两段；中间的餐厅戏挪到下一场。
- **次要角色台词改画外音**：让配角不出镜，只用语音 / 短信 / 字幕传递信息。

### producibility 改写的禁止动作（严禁触碰）

- **绝对不能删除标记为 protagonist / antagonist 的角色**。如果某场只剩
  主角和反派，没有可压缩的换景 / 群戏 / 配角，**直接跳过这场不要选**。
- **绝对不能"减少主角同框"**。男一女一的对手戏是 LoRA 摊薄的核心收益场景，
  减少他们的同框等于增加 LoRA 训练摊薄难度，**反向**。
- **不能把主角拆成单独场**：「让顾聿之去 A 场，姜栀枝去 B 场」不是 producibility
  优化，是把 1 场变 2 场，反而加成本。

### few-shot

**Bad rationale**（典型胡说八道，会被 critic 退回）：
> 「该场次中顾聿之和裴鹤年同时出现，增加了跨集角色复现的责任。建议只保留
> 顾聿之一人，或者将裴鹤年的部分移到另一场次。」
>
> ↑ 这条建议错在哪：顾聿之、裴鹤年都是主角（双男主），他们的同框
> 是 LoRA 摊薄的优势场景，**不是**复现负担。这条建议方向反了。

**Good rationale**：
> 「本场（第 5 集 / 第 9 场）是姜栀枝去律所咨询的过场戏，出现 4 个律所角色
> （前台、实习律师、合伙人、秘书）和姜栀枝本人。前台、实习律师、秘书均
> 只在本场出现，是典型的低复用次要角色；合伙人在本集和第 7 集出现共 2 次；
> 同框 5 人是 producibility 短板。」

**Good expected_changes**：
> 「合并前台与实习律师为「接待员一号」单角色；秘书改为画外音；
> 保留合伙人（跨集复用）和姜栀枝；同框压缩到 3 人；台词总量与原文同量级。」
