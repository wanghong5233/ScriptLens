## 改写维度：payoff（兑现力）

### 改写动作清单

1. **扩写高潮段**：如果本场是已经铺垫了几集的"打脸 / 救赎 / 表白"高潮场，
   把对应段落从 5 行扩到 15-20 行。具体扩写方向：
   - 加 1-2 段关键证据呈现（录音 / 视频 / 邮件 / 现场目击）
   - 加 1 段强情绪反应（甩耳光、摔东西、拍桌、泪流满面）
   - 加 1 段闭环陈述（主角明确说出"这就是我等了 12 集的时刻"）
2. **拉直接的强情绪台词**：把温和说辞改为直接、狠、准的台词。
   例：「你做得不太对」→「你毁了我整整一个青春，我让你今天就跪下来道歉」。
3. **明确闭环**：如果本场是悬念解答场，让答案在场内**完全揭开**，不要留半截。

### 禁止动作

- 不要因为情绪强度而引入新主角冲突（爽点应该是已有冲突的爆发，不是新冲突）。
- 不要把铺垫场强行改成爽点（节奏需要张弛）。
- 不要为了情绪强度而让反派或主角"瞬间黑化 / 瞬间洗白"，那是逻辑塌缩。
