## 改写维度：producibility（可生成力）

### 改写动作清单（按可执行性 / 安全性递减）

1. **删除无台词工具人**：场内纯背景出现、没有任何台词的角色直接删掉，让镜头集中在
   主角身上。例：「3 位路人甲乙丙站在门口」→ 移除这 3 个角色 + 调整描写。
2. **配角台词改画外音 / 短信 / 字幕**：让配角不出镜，只用语音 / 短信文字 / 字幕传递
   信息。例：「（配角）小姐，老板找你」→「（手机推送）老板：现在过来一下」。
3. **合并次要角色**：把出现 1 次的角色 A 和出现 1 次的角色 B 合并为一个跨集
   出现的统一角色 C。
4. **压缩群戏**：把 5 人以上同框场改为「3 人正面 + 2 人画外音」，或者只保留主角和
   反派 + 1 个见证人。
5. **合并相邻换景**：把"主角先在公司、然后去餐厅、然后回家"压缩到"主角在公司加班 →
   接到电话 → 直接回家"两段。

### 禁止动作（违反必触发 critic 退回）

- **绝对不能删除标记为 protagonist / antagonist 的角色**。如果指令暗示删主角，
  把它降级为"压缩主角戏份 / 主角戏改为独白 / 减少主角台词条数"，**不要**让主角
  从场内消失。
- **绝对不能"减少主角同框"**。男一女一的对手戏正是 LoRA 摊薄收益场景，
  减少他们的同框等于反向操作。
- **不要把主角拆到不同的场**。如果 plan 暗示「让顾聿之去 A 场，姜栀枝去 B 场」，
  视为非法指令，保留原文 + 注释。

### 兜底注释模式

如果 `expected_changes` 整段都是要求删主角 / 拆主角 / 让主角让位，整个执行不可达：

```
（保留原文不修改）
# execute: 指令要求删除/压缩主角 [姓名]，违反 producibility 改写硬约束（主角必复用），
# 保留原文。如确需压缩本场制作成本，建议改为：合并 [次要角色 A]+[次要角色 B] 为 [统一角色]，
# 或将 [配角姓名] 的台词改为画外音。
```
