## 改写维度：hook（抓人力）

### 改写动作清单（按优先级递减）

1. **强冲突 / 强悬念前置**：把场内最有张力的一句台词或一句心理活动挪到本场第一句。
   原本铺垫的环境 / 心情描写后置到第二段。
2. **第一句台词必须直指主线矛盾**：例如「这婚我离定了」「他还活着」「你怎么敢回来」
   「明天就把房子卖了」之类的明确指向，**不要**模糊的「天气真好」「我们谈谈」。
3. **集末加 cliffhanger**（仅当本场是当集最后一场时）：用主角内心独白 / 反派镜头 /
   神秘电话作为收尾。
4. **去掉拖沓铺垫**：连续 3 行以上的环境描写 / 内心独白要压缩到 1-2 行。

### 禁止动作

- 不要为了 hook 信号引入额外角色（开场第一句应该是已有主角的台词）。
- 不要把整场重写成纯独白 — 独白容易让用户疲劳。
- 不要把次要角色（配角 / 龙套）塞进开场第一句 — 开场必须围绕主角。
