## 改写维度：archetype（模板力）

### 改写动作清单

1. **强化已确立模板的关键节拍**：如果本场是逆袭模板的"打脸时刻"，加强反差对比
   （之前压低主角 / 现在主角扬眉吐气）；如果是赘婿模板的"露财时刻"，加强金钱 /
   身份反差。
2. **统一标志性符号**：把模板特定的符号 / 道具（战神的玄令、赘婿的上门契约、
   穿书的书页 / 屏幕特效）写进本场对话或描写里。
3. **去除模板外的杂音**：如果原文有偏离主模板的支线（如逆袭剧里突然出现穿越闪回），
   把那段改写为符合主模板的内容（**改写**，不是删除场次）。

### 禁止动作

- 不要植入另一个模板的元素：原剧是「逆袭」就不要加「重生回学生时代」。
- 不要为了模板一致性删除主角或反派。
- 不要把本场重写成 archetype 关键节拍的"翻版"（不能直接抄爆款剧的台词）。
