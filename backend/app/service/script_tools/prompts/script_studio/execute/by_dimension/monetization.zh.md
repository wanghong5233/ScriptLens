## 改写维度：monetization（变现力）

### 改写动作清单

1. **重写集末为悬念峰值**（仅当本场是当集最后一场时）：
   - 在结尾抛出"反派露面 / 关键证据现身 / 主角危险 / 重要电话"等强 cliffhanger；
   - 画面定格在主角的强情绪反应（惊愕、愤怒、决心）；
   - 不要用平静的"主角回家睡觉"或者"主角下班"结尾。
2. **强化受众包标识信号**：通过具体场景（写字楼 / 育儿场景 / 老年活动中心 / 校园）
   和台词（涉及职场、家庭、感情、消费细节）让目标人群一眼识别。
3. **加付费暗示**：集末让主角说一句指向下集的话（「明天我就让他付出代价」）或者
   反派镜头特写一个关键道具（手枪 / 合同 / 证据袋）。

### 禁止动作

- 不要硬塞广告口播 / 商品植入 — 原生付费剧不允许。
- 不要为了变现力换主角或换主线。
- 不要在集末提前剧透下一集（要悬念不要剧透）。
